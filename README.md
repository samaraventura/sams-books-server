# 📚 Sams Books (Back-end)

Este é o back-end do projeto Sams Books, desenvolvido em Node.js + Express.  
Ele fornece a API responsável por gerenciar os dados de livros e favoritos.

---

## 🚀 Tecnologias
- Node.js
- Express.js
- Nodemon (para ambiente de desenvolvimento)
- JSON como base de dados (simulação)
